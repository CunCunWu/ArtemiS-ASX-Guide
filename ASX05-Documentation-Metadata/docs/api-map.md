# ASX 05 API 地图

| 任务 | 类型 |
| --- | --- |
| 创建空文档 | `Documentation.Create` |
| 读取 User Documentation | `DocumentationReader` |
| 写 User Documentation | `DocumentationWriter` |
| 读取/写模板 | `TemplateReader` / `TemplateWriter` |
| 读取旧 UDI | `LegacyUdiReader` |
| UDI 转换 | `DocumentationConverter` |
| 创建分组 | `Form.Create` |
| 创建字段 | `TextField`、`DateField`、`IntegerField`、`RealField` 等 |

核心程序集：`HEADacoustics.API.Documentation.dll`；许可证：`ASX_05_DocumentationAndMetadataAPI`。
