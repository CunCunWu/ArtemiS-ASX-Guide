# ASX 09 API 地图

| 任务 | 类型/方法 |
| --- | --- |
| 读取 | `ReportReader.ReadFromFile` / `TryReadFromFile` |
| 数据源 | `DataSourceCollection.GetNames/GetByName` |
| 替换数据 | DataSource `Exchange` |
| 复制数据源 | `DuplicateWithBindings` |
| 保存 HRPX | `ReportWriter.WriteToFile` / `TryWriteToFile` |
| 导出 PDF | `ReportExporter.ExportToPdf` |
| 导出 PPTX | `ReportExporter.ExportToPowerPoint` |
| 页范围 | `ExportSettings` |
| 单位修改 | Shared `QuantityAndUnitOptions` |

程序集：Reporting、License、Shared；许可：`ASX_09_ReportingAPI`。
