# ASX 06 官方示例索引

目录：`%ASX_DIR%\Documentation\addin\examples`

## C#

- `Time2TimeAddin.zip`：Filter，采样值乘倍率；
- `CrestFactorVsTime.zip`：Analysis，滑动 Crest Factor。

## MATLAB M-file

- `FftFromRecording.zip`：Analysis 2D；
- `Add6dBTo2DAnalysis.zip`：Post-Analysis 2D；
- `Multiply2DAnalysis.zip`：带参数的 Post-Analysis 2D。

## MATLAB Compiler

- `Add6dBTo2DAnalysisWithInputParser.zip`：编译为独立 EXE，目标机器需要匹配 MATLAB Runtime。

完整类型、属性和运行规则位于 `types.html`、`properties.html`、`Executables.html`、`M_Files.html`。
