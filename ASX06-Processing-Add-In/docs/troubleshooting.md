# ASX 06 排错

| 症状 | 检查 |
| --- | --- |
| EXE 启动即失败 | 参数、引号、依赖、ASX 01 许可证 |
| 超时 | 死循环、模态窗口、算法过慢、默认 30 分钟 |
| 输出无效 | Add-In 类型、DataKind、轴、单位、数据长度 |
| MATLAB 修改未生效 | 隐藏 MATLAB 进程仍缓存旧函数 |
| M-file 串行变慢 | ASX 06 MATLAB 模式单进程顺序执行 |
| Python 脚本不能直接选择 | Add-In File Path 要求受支持 M-file/P-file 或 EXE；需封装 EXE |
