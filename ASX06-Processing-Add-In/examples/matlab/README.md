# MATLAB Add-In examples

ASX 18.1 已随离线帮助提供经过验证的 M-file 示例，位于：

```text
%ASX_DIR%\Documentation\addin\examples
```

使用 `FftFromRecording.zip`、`Add6dBTo2DAnalysis.zip` 和 `Multiply2DAnalysis.zip`。本仓库不重复分发官方 ZIP。

注意：

- ASX 18.1 帮助标注直接 M-file 模式要求 MATLAB R2022a 或更早版本；
- M-file 输出到命令窗口会被视为错误；
- M-file 进程顺序执行并缓存函数；
- MATLAB Compiler 输出需要目标机器安装匹配的 MATLAB Runtime。
