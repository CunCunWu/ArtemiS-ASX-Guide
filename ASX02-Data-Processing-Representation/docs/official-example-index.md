# ASX 02 官方示例索引

默认目录：`%ASX_DIR%\Documentation\api_remote`

| 页面 | 场景 | 语言 |
| --- | --- | --- |
| `ScreenPositioningExample.html` | 启动 GUI 并设置窗口位置 | C#、Python、MATLAB |
| `AutomationProjectExample.html` | 打开 Automation Project、替换源并计算 | C#、Python、MATLAB |
| `AutomationProjectVariableModificationExample.html` | 读取和修改项目变量 | C#、Python、MATLAB |
| `PoolProjectCalulationExample.html` | 配置 Source Pool、Mark 并计算 | C#、Python、MATLAB |
| `CalculatorExample.html` | 用 Calculator 执行 HPSX Job | C#、Python、MATLAB |
| `ReportDataExchangeExample.html` | 替换 Report 数据源 | C#、Python、MATLAB |
| `ReportExportExample.html` | 从模板创建并导出 Report | C#、Python、MATLAB |

接口和兼容性说明还应阅读 `creation.html`、`using.html`、`usingASXRemote.html` 和 `compatibility.html`。
